Work done

From one 22 MB file to an editable template.

The live site at fstamparetail.netlify.app was a single bundled file with every image, video, font and script encoded inside it. It was unpacked into normal, named files, matched against the original, then refined section by section.

Rebuild

  • Decoded 65 embedded files into named assets (alex-wright.jpg, hero-bg.jpg)
  • Split styles into 3 CSS files and scripts into 3 JS files
  • Replaced 4 MB of design-tool code (React + Babel) with a 78-line theme.js
  • Verified against the live site: identical page height (18,244 px) and section sizes
  • Carousel and tab counts now detected automatically (were fixed at 5)

Design refinements

  • Opening: navy screen, geometric pattern draws out from the logo (replaced lime + stair panels)
  • Section labels: bold tracked Arial, title then green dash
  • Geometric line pattern behind National Reach and Results That Speak
  • Kinetic band in EB Garamond + Arial; calmer motion
  • Every section on one 1360 px grid line; spacing fixes throughout

Content & function

  • National Reach map enlarged beside the stats
  • Process tabs larger; headings on one line
  • Listings window shows only the Buildout listings, with a clear link to franklinst.com
  • Header logo links to franklinst.com
  • Logo rows: no side fades

System & tools

  • new-deck.sh starts a deck from any template
  • check-deck.py catches missing files, tab/panel mismatches, TBDs, bad links
  • preview.sh serves a deck locally
  • unbundle.py converts any future single-file export
  • 7 guides, 2 intake questionnaires, brand and team libraries, dated template backups

Rules to remember

Easy to miss, caught by QC.

Never edit a template for one deckWork in the deck's 05_Site. Template changes are for every future deck, logged in CHANGELOG.md.
Tabs and panels match by numberAdd or remove both, then renumber from 0 (data-panel, goPlatform(n), panel-n).
One dot per carousel carddata-i runs 0, 1, 2 with no gaps; only the first card is active.
Logo rows list every logo twiceThat makes the loop seamless; edit both halves.
"N Actions" must match the listEach timeline badge counts its checklist items.
New section → add it to the railAdd ['id','Label'] to var CH in js/motion.js so the side dots and clicker stop there.
Same file name, no code changeReplace hero-bg.jpg with a new photo of the same name and size (see Asset Specs).
Never invent numbersMark unknowns TBD; the QC check blocks publishing until they're filled.
