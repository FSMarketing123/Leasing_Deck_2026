# Franklin Street Deck Brand Guide

Taken from the Leasing template (`01_Templates/Leasing/css/styles.css`, `:root`).

## Colors

| Name | Hex | Used for |
|---|---|---|
| Navy | `#003349` | primary text, dark sections (hero card, market, CTA) |
| Teal | `#005670` | italic headline words on light sections, links |
| Sky | `#7BA7BC` | eyebrows, roles, small labels |
| Green | `#C6D83B` | Franklin Street green — accent bars, highlight words on dark, buttons |
| Charcoal | `#3F4443` | values eyebrow in Advantage |
| Cream | `#F7F6F2` | light section backgrounds |
| White | `#FFFFFF` | cards, light sections |
| Map glow | `#E8FF3D` | map dots only |
| Footer | `#001F2E` | footer bar |

Green is an accent — use it on navy, not as body text on white.

## Type

| Role | Font | Notes |
|---|---|---|
| Headlines, big numbers, names | **Libre Baskerville** 400, italic for highlight words | `fonts/libre-baskerville-*` |
| Body copy | **Open Sans** 300–600 | `fonts/open-sans-*` |
| Eyebrows, labels, buttons, tabs | **Arial Narrow** bold, UPPERCASE, wide letter-spacing | system font |

## Headline pattern

Two lines, the second (or last word) in italic accent color:
*Meet The* ***Team.*** · *Florida.* ***Covered.*** · *Results That* ***Speak.***
End headlines with a period.

## Eyebrow pattern

Small caps label with an arrow tick before it: `→ THE FRANKLIN ADVANTAGE`.

## Logo

`brand-logo/franklin-street-logo.png` — white, 2346 × 430. The site turns it navy
automatically on light sections. Don't stretch or recolor it by hand.
