# Data

Keep the source for every number shown on the site.

- `placer-ai/` — visit counts, trade area, demographics exports (note the date range)
- `demographics/` — ESRI / census reports, radius rings
- `site-plans/` — current site plan, availability, stacking plan
- `availability-reports/` — the PDF/link the market map clicks through to
- `financials/` — capital markets: rent roll, T-12 operating statements, CAM reconciliations, loan docs
- `sales-comps/` — capital markets: comparable sales (property, date, price, $/SF, cap rate)

Add a line to `sources.md` for each stat: *stat · value · source · date pulled*.
